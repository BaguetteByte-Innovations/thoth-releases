# Thoth — téléchargements

Thoth est une suite de gestion des identités pour l'éducation : elle alimente Active Directory
depuis les sources de l'école (SIECLE, CSV…), crée les dossiers des utilisateurs sur les
serveurs de fichiers et prépare les postes. Présentation et documentation :
[thoth-iam.com](https://thoth-iam.com/).

**[Télécharger la dernière version](https://github.com/BaguetteByte-Innovations/thoth-releases/releases/latest)**

## Programme bêta

Thoth est en bêta. Pour obtenir une licence de test : [thoth-iam.com/essai](https://thoth-iam.com/essai/).
